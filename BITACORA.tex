\section*{2026-06-12 — Etapa 1: portales objetivo (M1 Ingesta)}
\addcontentsline{toc}{section}{2026-06-12 — Etapa 1: portales objetivo}

\subsection*{Qué se hizo}
\begin{itemize}
  \item Investigación de los principales portales para comprar inmuebles en CDMX
        y la ZMVM, cruzando rankings de tráfico de \textbf{Similarweb} (top 5,
        may-2026) y \textbf{Semrush} (abr-2026, visitas/mes).
  \item Se excluyeron sitios con poco inventario CDMX o no-portal
        (craigslist, zillow, idealista, foros).
  \item Se creó \codigo{config.yml} con la lista \codigo{portales} (objetos
        \codigo{\{nombre, sitio\}}).
\end{itemize}

\subsection*{Decisiones / notas}
\begin{itemize}
  \item Orden por tráfico nacional; todos tienen inventario en CDMX/ZMVM.
  \item Trovit es agregador (útil para probar deduplicación en M1); EasyBroker
        es backend tipo MLS con API. Alternos a futuro: Metroscubicos, Century21,
        RE/MAX MX.
\end{itemize}
